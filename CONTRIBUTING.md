# Contribuindo com novos laboratórios

Este repositório funciona como um **diário técnico de experimentos documentados**.

1. Crie uma pasta em `labs/<nome-curto-do-case>/`.
2. Copie [o modelo de estudo](templates/case-study-template.md) para `README.md`.
3. Registre o escopo e a autorização do teste.
4. Inclua procedimentos reproduzíveis e o resultado observado, sem inventar evidências.
5. Revise saídas de terminal, screenshots e gravações, removendo credenciais e dados pessoais.
6. Registre claramente os testes inconclusivos e os pontos ainda pendentes.
7. Adicione uma linha ao índice de laboratórios no README da raiz.

### Convenção para commits

- `docs: documentar análise de segurança SMB`
- `lab: adicionar estudo de logs de autenticação`
- `fix: corrigir procedimento de reprodução`

### Cuidado com a publicação

A conta, a rede e os computadores utilizados em cada estudo devem ser próprios ou expressamente autorizados. Não desative recursos de proteção apenas para obter uma captura. Nunca adicione senhas, arquivos de credenciais, tokens ou dados pessoais.
