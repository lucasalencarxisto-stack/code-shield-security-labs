# Evidências do laboratório

O projeto pode ser publicado **sem prints de terminal administrativo**. Evidências textuais provenientes dos testes, revisadas e sanitizadas, são mais úteis que imagens que exponham informações pessoais.

## Registro disponível

- [09 — Escrita negada com conta de leitura](09-escrita-negada.md) — saída real informada pelo operador, com caminho e IP omitidos.

## Sobre screenshots

Só adicionar capturas **reais**, depois da revisão de dados sensíveis. Não fabricar telas que imitem resultados. Se o sistema bloquear uma captura, respeitar essa restrição e usar registros textuais.

Veja [docs/capturas.md](../docs/capturas.md).
